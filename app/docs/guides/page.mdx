## Component overview

| Component | Description |
|-----------|-------------|
| `SimulationParameters` | Coordinate system, wavelength, device |
| `Wavefront` | Complex field amplitude |
| `Element` | Base class of all optical elements |
| `LinearOpticalSetup` | Sequential optical system |
| `Detector` | Turns a field into an intensity image |
| `DetectorProcessorClf` | Classification from detector zones |
| `specs` | Serialising and exporting a setup |

## Suggested reading order

1. **SimulationParameters** — the foundation of every calculation
2. **Wavefronts** — creating input fields
3. **Elements** — the optical components
4. **Optical systems** — assembling setups
5. **Detectors** — measuring the result
6. **Optimisation** — training a system
