## Running the examples

```python
# minimal template used throughout the tutorials
import torch
from svetlanna import SimulationParameters, Wavefront
from svetlanna.units import ureg

params = SimulationParameters.from_ranges(
    x_range=(-2*ureg.mm, 2*ureg.mm), x_points=512,
    y_range=(-2*ureg.mm, 2*ureg.mm), y_points=512,
    wavelength=632.8*ureg.nm
)

wf = Wavefront.gaussian_beam(params, waist_radius=0.5*ureg.mm)
print(f"Ready. Field shape: {wf.shape}")
```

<Callout type="warning">
To run on a GPU, install the CUDA build of PyTorch and call `params.to('cuda')` **before**
creating any elements.
</Callout>
